# 作业 2 算例：Timoshenko 梁单元的锁死与收敛

本目录包含**批量扫描数据**和**绘图脚本**。所有有限元计算都在 C++ 程序里完成，
MATLAB 只负责读数据、画图。

## 一、算例设置

| 项目 | 取值 |
|---|---|
| 结构 | 悬臂梁，左端固支 |
| 材料 | E = 200 GPa，ν = 0.3 |
| 截面 | 矩形，宽 b = 0.1 m，高 h 随细长比变化 |
| 梁长 | L = 1.0 m |
| 剪切修正因子 | k_s = 5/6（矩形截面） |
| 载荷 | 端部集中力 P = 1000 N，或端部弯矩 M = 1000 N·m |

**扫描的参数空间**

| 维度 | 取值 |
|---|---|
| 单元类型 | `BEAM2`（2 节点线性）/ `BEAM3`（3 节点二次） |
| 单元数 | 1, 2, 4, 8, 16, 32, 64, 128 |
| 积分方案 | `FULL` / `REDUCED` / `SELECTIVE` |
| 载荷 | 端部集中力 / 端部弯矩 |
| 细长比 h/L | 0.5, 0.3, 0.2, 0.1, 0.05, 0.02, 0.01, 0.005, 0.001 |

共 2 × 8 × 3 × 2 × 9 = **864 个算例**。

## 二、复现步骤

**1. 编译**

在 Visual Studio 里生成全部（`Ctrl+Shift+B`），或命令行：

```
out\build\build_feml.bat
```

**2. 生成数据**（在仓库根目录）

```
out\build\x64-Debug\bin\beam_sweep.exe examples\beam_sweep\beam_sweep.csv
```

输出 `扫描完成：864 个算例` 和 CSV 文件的绝对路径。

**3. 绘图**

在 MATLAB 里把当前目录切到 `examples/beam_sweep/`，运行：

```matlab
plot_sweep
```

生成三张图和一份文字汇总表。

> MATLAB 使用清华的网络许可证（`matlab.cic.tsinghua.edu.cn:27000`），
> 需要接入校园网或 VPN。

## 三、CSV 列说明

| 列 | 含义 |
|---|---|
| `elementType` | `BEAM2` / `BEAM3` |
| `elementCount` | 单元数 |
| `scheme` | `FULL` / `REDUCED` / `SELECTIVE` |
| `loadType` | `LOAD`（端部集中力）/ `MOMENT`（端部弯矩） |
| `hOverL` | 细长比 h/L |
| `tipW` | **数值解**：端部挠度 |
| `tipTheta` | **数值解**：端部转角 |
| `w_timoshenko` | **Timoshenko 解析解**（含剪切变形） |
| `theta_timoshenko` | 同上 |
| `w_eulerBernoulli` | **材料力学解**（Euler-Bernoulli，不含剪切） |
| `theta_eulerBernoulli` | 同上 |

**为什么给两种参考解**

- `w_timoshenko` 用来检验数值解**是否收敛到真解**
- `w_eulerBernoulli` 是**作业要求对比的对象**（"与材料力学解的差异"）

两者在细长梁上趋于一致（剪切效应消失），在粗短梁上差别明显。

## 四、三张图说明什么

**图 1 · 细长比扫描（核心）**

1 个单元、端部集中力，横轴 h/L（对数），纵轴 `w_num / w_Euler-Bernoulli`。

| 组合 | 细长极限 | 含义 |
|---|---|---|
| `BEAM2 + FULL` | → 0 | **剪切锁死** |
| `BEAM2 + REDUCED` | → 3/4 | 不锁死，但弯曲项被积成 L³/4EI，有 25% 系统偏刚 |
| `BEAM3 + FULL` | → 3/4 | 不锁死（二次插值保留了纯弯模式） |
| `BEAM3 + REDUCED` | 恒为 1 | **1 个单元就精确** |

**图 2 · 网格收敛**

固定 h/L = 0.05，横轴自由度数，纵轴相对材料力学解的误差。
`BEAM2 + FULL` 的误差下降明显更慢（258 个自由度时仍为 $5.8\times10^{-3}$），
其余三条在几十个自由度时即降到 $10^{-3}$ 量级。
所有曲线最终收敛到同一个平台 $\approx 1.95\times10^{-3}$ —— 该值即剪切变形
造成的固有差异，意味着离散误差已可忽略。

**图 3 · 纯弯 vs 集中力**

左右对比两种载荷。纯弯时剪切应变为零，所以减缩积分在任意单元数、
任意细长比下都精确 —— 误差**只**来自弯曲项，与剪切锁死无关。
这从另一个角度印证了锁死的机制。

## 五、备注

- `SELECTIVE` 与 `REDUCED` 的曲线**完全重合**。这不是程序 bug：
  弯曲项的 `BᵀDB` 是常数（2 节点）或二次（3 节点），
  减缩所用的点数对它而言仍然精确，所以两者只在剪切项上有差别，
  而这两种方案的剪切项点数相同。
- CSV 里的 `nan` 表示该算例求解失败（正常情况应为 0 个）。
